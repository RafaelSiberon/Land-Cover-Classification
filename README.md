# GeoAI Project 1 — Remote Sensing Classification

## Descripción
Clasificación de agua y cobertura del suelo usando datos espectrales MODIS (Lake Powell, NASA CISTO).

## Notebooks
- `notebooks/proyecto1_water_classification.ipynb` — Parte 1: Clasificación de Agua
- `notebooks/proyecto1_land_cover_classification.ipynb` — Parte 2: Clasificación de Cobertura del Suelo

## Dataset
[MODIS Lake Powell — NASA CISTO](https://huggingface.co/datasets/nasa-cisto-data-science-group/modis-lake-powell-toy-dataset)
